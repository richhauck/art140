Tabs to Accordion

Resize the window below 767px to switch from tabs to an accordion.

Overview

One set of markup, two layouts. On wide screens the sections display as tabs; on narrow screens they collapse into an accordion so nothing gets cramped.

The selected tab and the open accordion item stay in sync when the layout changes.

Features

  • Correct ARIA roles for each mode (tablist/tab/tabpanel vs. aria-expanded)
  • Arrow keys, Home and End to move between tabs
  • Animated accordion using CSS grid, no height measuring
  • Collapsed panels are inert, so keyboard focus skips them

Can more than one accordion item be open?

Yes. Set data-single on the .tabs element if you want only one open at a time.

How do I change the breakpoint?

Update the value in both the CSS media query and the data-breakpoint attribute (defaults to 767px).
